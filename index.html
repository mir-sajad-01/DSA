Core Concept

The Perceptron — Complete Understanding

The perceptron is the atomic building block of all neural networks. Master this and everything else follows.

Definition

A Perceptron is a mathematical model of a single neuron. Invented by Frank Rosenblatt in 1958. It takes multiple numerical inputs, multiplies each by a weight (importance), sums them, adds a bias, and passes through an activation function to produce a binary output.

Visual of a Single Perceptron

The Complete Perceptron Formula

Step 1 → z = (w₁×x₁) + (w₂×x₂) + (w₃×x₃) + b = Σ(wᵢxᵢ) + b
Step 2 → ŷ = f(z)     [f = activation function]

Worked Example (using numbers from the diagram):

Step-by-Step Calculation

Given: x₁=0.8, x₂=0.5, x₃=0.3 · w₁=0.6, w₂=0.4, w₃=0.2 · b=0.1

z = (0.6×0.8) + (0.4×0.5) + (0.2×0.3) + 0.1 = 0.48 + 0.20 + 0.06 + 0.1 = 0.84

ŷ = sigmoid(0.84) = 1/(1+e⁻⁰·⁸⁴) = 1/(1+0.431) = 0.699 ≈ 0.70

Interpretation: 70% probability of class 1.

Original Perceptron — Step Function

Rosenblatt's original perceptron used a step function for binary decisions:

Output = 1  if z ≥ threshold   |   Output = 0  if z < threshold

Perceptron Learning Rule

The perceptron learns by adjusting weights based on errors:

wᵢ(new) = wᵢ(old) + η × (y - ŷ) × xᵢ

Where η (learning rate, e.g. 0.01) controls how much to adjust, y is true label, ŷ is predicted label.

What Perceptron CAN Solve
  • AND gate (linearly separable)
  • OR gate (linearly separable)
  • NOT gate
  • Any linearly separable classification
What Perceptron CANNOT Solve
  • XOR gate (NOT linearly separable)
  • Any problem where classes cannot be separated by a straight line/plane
  • Complex real-world patterns
  • Solution → Use MLP (next section)

Multi-Layer

Multi-Layer Perceptron (MLP)

Stack multiple layers of perceptrons → solve ANY problem. The "deep" in deep learning comes from many hidden layers.

Structure of an MLP

Why Hidden Layers are Powerful

Each hidden layer learns increasingly abstract features:

LayerWhat it learns (image example)What it learns (text example)
Layer 1Edges and simple texturesIndividual character patterns
Layer 2Shapes (corners, curves)Word-level patterns
Layer 3Parts (eyes, wheels, legs)Phrase-level patterns
Layer 4+Whole objects (faces, cars)Sentence meaning, intent

Universal Approximation Theorem

Theoretical Foundation

A feedforward neural network with at least one hidden layer and a sufficient number of neurons can approximate any continuous function to any desired accuracy. This is why MLPs are called "universal function approximators".

Full ANN

Artificial Neural Network (ANN) — Complete Architecture

ANN is the umbrella term. Everything from the simple MLP to CNNs and RNNs are types of ANNs.

Types of ANN

Feedforward ANN

Information flows only forward — input → hidden → output. No cycles. The simplest type. MLP is a feedforward ANN. Good for: classification, regression.

Recurrent ANN (RNN)

Has feedback loops — output goes back as input. Has "memory" of previous inputs. Good for: text, speech, time series.

Convolutional ANN (CNN)

Uses convolution operation. Shared weights. Local connectivity. Hierarchical feature learning. Good for: images, video.

Autoencoder

Encoder compresses input → bottleneck → decoder reconstructs. Learns compressed representation. Good for: dimensionality reduction, anomaly detection.

Computation

Forward Pass — How Predictions are Made

The forward pass is how a neural network produces an output. It's pure math — matrix multiplications and activation functions.

Matrix Form — How it Actually Runs

For each layer, we compute:

Z = W · X + b    (linear transformation)
A = f(Z)    (apply activation function)

Where W is the weight matrix, X is the input, b is bias vector, f is the activation function.

Concrete Example — 2-Layer Network

Network: 2 inputs → 3 hidden → 1 output

Input: X = [0.5, 0.8] (2 features)

Hidden Layer: W₁ (3×2 matrix), b₁ (3×1) → Z₁ = W₁·X + b₁ → A₁ = ReLU(Z₁)

Output Layer: W₂ (1×3 matrix), b₂ → Z₂ = W₂·A₁ + b₂ → ŷ = sigmoid(Z₂)

The output ŷ is a single number between 0 and 1 → probability of class 1.

Computational Graph

Input X ↓ [Layer 1: Z₁ = W₁·X + b₁] → [A₁ = ReLU(Z₁)] ↓ [Layer 2: Z₂ = W₂·A₁ + b₂] → [A₂ = ReLU(Z₂)] ↓ [Output: Z₃ = W₃·A₂ + b₃] → [ŷ = sigmoid(Z₃)] ↓ Prediction ŷ ↓ Compare with true label y ↓ [Loss L = -y·log(ŷ) - (1-y)·log(1-ŷ)]

Learning

Backpropagation — How Neural Networks Learn

Backpropagation is the algorithm that makes neural networks learn. It uses calculus (chain rule) to figure out which weights caused the error and how to fix them.

The Big Picture — 4 Steps

  1. Forward Pass: Feed input data through the network → get prediction ŷ
  2. Compute Loss: Measure how wrong the prediction is: L = Loss(y, ŷ)
  3. Backward Pass: Use Chain Rule to compute ∂L/∂w for every weight — how much each weight contributed to the error
  4. Update Weights: Adjust every weight in the direction that reduces loss: w = w − η × ∂L/∂w

Chain Rule — The Mathematical Heart

The chain rule from calculus lets us compute how a change in any weight affects the final loss, even through many layers:

∂L/∂w₁ = (∂L/∂ŷ) × (∂ŷ/∂z₂) × (∂z₂/∂a₁) × (∂a₁/∂z₁) × (∂z₁/∂w₁)

Each term is a local gradient. We multiply them together to get the gradient for any weight, no matter how deep it is in the network.

Weight Update — Gradient Descent

w := w − η × ∂L/∂w

Intuition: If ∂L/∂w is positive → loss increases as w increases → decrease w. If negative → loss decreases as w increases → increase w. The gradient always points uphill; we subtract to go downhill toward minimum loss.

Vanishing Gradient Warning

With sigmoid/tanh activations, gradients get multiplied by values close to 0 at each layer during backprop. After 10+ layers, the gradient for early layers becomes essentially 0 → weights stop learning. This is the vanishing gradient problem. Solution: Use ReLU activation.

Non-Linearity

Activation Functions — Complete Guide

Without activation functions, a 100-layer network collapses to just a linear transformation. Activation functions give networks the power to learn ANY function.

Why Activation Functions are Essential

Without Activation (Linear Only)

W₃(W₂(W₁·x)) = (W₃W₂W₁)·x = W·x — Still just linear! No matter how many layers you stack, it's equivalent to one linear layer. Useless for complex problems.

With Activation (Non-Linear)

f(W₂·f(W₁·x)) ≠ any linear transformation. Each layer creates a new non-linear transformation. Stacking many = can approximate any function.

Dying ReLU — Explained with Example

The Dying ReLU Problem

ReLU outputs 0 for any z ≤ 0. When z is negative: gradient = 0 → weight update = 0 → weight never changes again. The neuron is "dead" — permanently outputs 0 regardless of input.

Cause: Large negative bias or very high learning rate.

Fix 1: Leaky ReLU — f(z) = 0.01z for z≤0 (small non-zero gradient keeps neuron alive)

Fix 2: Careful weight initialization (He initialization)

Fix 3: Lower learning rate + batch normalization

Measurement

Loss Functions — Measuring Errors

Loss functions measure how wrong the network's predictions are. The network's job is to minimize this number.

For Regression (predicting numbers)

Mean Squared Error (MSE)

MSE = (1/n) Σ(yᵢ − ŷᵢ)²

Squares errors so large errors are penalized heavily. Differentiable everywhere. Most common for regression.

Mean Absolute Error (MAE)

MAE = (1/n) Σ|yᵢ − ŷᵢ|

Treats all errors equally. More robust to outliers than MSE. Not differentiable at 0.

For Classification (predicting categories)

Binary Cross-Entropy

L = −[y·log(ŷ) + (1−y)·log(1−ŷ)]

For 2 classes. y ∈ {0,1}. Penalizes confident wrong predictions much more than uncertain ones.

Example: True y=1, predicted ŷ=0.9 → loss=0.10 (good). ŷ=0.1 → loss=2.30 (very bad!)

Categorical Cross-Entropy

L = −Σ yᵢ·log(ŷᵢ)

For multiple classes. Used with Softmax output. Only the true class's probability contributes to loss (other terms are 0).

Example: 3 classes [dog,cat,bird]. True=[1,0,0], Predicted=[0.7,0.2,0.1] → L=−log(0.7)=0.36

Adam — The Default Choice Explained

Adam (Adaptive Moment Estimation) combines two ideas:

Momentum (1st moment)

Keeps a running average of gradients. Like a ball rolling down a hill — it builds up speed in consistent directions. Helps escape flat regions and saddle points.

Adaptive Learning Rate (2nd moment)

Divides learning rate by √(running average of squared gradients). Parameters with large gradients → smaller steps. Parameters with small gradients → larger steps.

m = β₁·m + (1−β₁)·g     v = β₂·v + (1−β₂)·g²     w = w − η·m̂/√(v̂+ε)

Default values: β₁=0.9, β₂=0.999, η=0.001, ε=1e-8

Learning Rate — The Most Important Hyperparameter

Too High (e.g. 1.0)

Overshoots minimum. Loss oscillates wildly or explodes. Network diverges.

Just Right (e.g. 0.001)

Smooth convergence. Loss decreases steadily. Reaches good minimum.

Too Low (e.g. 1e-7)

Training is extremely slow. May get stuck in bad local minimum. Wastes compute.

Generalization

Overfitting, Underfitting & Regularization

The most important practical challenge: making your model work on new unseen data, not just memorize training data.

The Bias-Variance Tradeoff

Underfitting (High Bias)

Model too simple. Doesn't even learn training data well. Train error HIGH. Val error HIGH. Add more layers, neurons, train longer.

Good Fit

Model generalizes. Train error LOW. Val error ≈ Train error (small gap). This is the goal.

Overfitting (High Variance)

Model memorizes training data including noise. Train error very LOW. Val error HIGH. Big gap between them.

Regularization Techniques — Preventing Overfitting

L2 Regularization (Ridge/Weight Decay)Adds λΣw² to loss functionPushes all weights toward (but not exactly) zero. Spreads weight evenly.L_total = L + λΣwᵢ²
L1 Regularization (Lasso)Adds λΣ|w| to loss functionPushes many weights to exactly zero → sparse network → feature selectionL_total = L + λΣ|wᵢ|

Dropout — How It Works Exactly
  • Training: Each neuron independently zeroed with probability p (e.g. 0.5). Scale remaining by 1/(1−p) to maintain expected values.
  • Testing/Inference: Dropout is DISABLED. All neurons active. No scaling needed (already handled during training).
  • Effect: It's like training 2^n different network architectures simultaneously and averaging them.

Dimensionality

Curse of Dimensionality

As the number of features (dimensions) grows, data becomes exponentially sparse and machine learning becomes exponentially harder.

The Core Intuition

Imagine you have 100 training samples. How well do they "fill" the feature space?

Consequences in Practice

  1. Data sparsity: With 100 features, 1000 training samples are microscopic relative to the possible input space. Every new test sample is far from any training sample.
  2. Distance metrics break down: In high dimensions, all points become approximately the same distance from each other. K-NN, SVM, and other distance-based methods fail.
  3. Exponentially more data needed: To maintain data density in d dimensions, you need N^d samples. 10 samples for 1D → 10^100 for 100D.
  4. Overfitting becomes trivial: With more features than samples, a model can perfectly memorize training data by using spurious feature combinations.
  5. Computational explosion: Training time grows polynomially or exponentially with dimensions.

Solutions

SolutionTechniqueHow It Helps
Linear Dim. ReductionPCA (Principal Component Analysis)Projects to k dimensions keeping maximum variance. 1000D → 50D while keeping 95% of information.
Non-linear Dim. Reductiont-SNE, UMAPMaps high-dim data to 2D/3D preserving local structure. Used for visualization.
Feature SelectionLasso (L1), RFE, information gainRemoves irrelevant features before training. Direct reduction of dimensions.
Deep Learning EmbeddingsAutoencoders, Word2VecNeural network learns compact low-dimensional representation. 50,000-word vocab → 300-dim vector.
RegularizationL1, L2, DropoutPrevents model from exploiting spurious high-dimensional correlations.

Vision

Convolutional Neural Networks (CNN) — Deep Dive

CNNs are specialized for grid-like data (images, video). They learn to detect features using shared filters — the key to efficient vision systems.

Why Not Regular ANN for Images?

The Problem

A 224×224 color image has 150,528 pixels (inputs). A fully connected layer with 1000 neurons would require 150,528 × 1,000 = 150 million parameters in just one layer!

AlexNet would need billions of parameters. VGGNet would need trillions. Also, FC layers have no sense of spatial structure — nearby pixels have no special relationship.

CNN's Three Key Ideas

Local Connectivity

Each neuron only connects to a small local region of the input (receptive field), not all pixels. Captures local patterns like edges.

Weight Sharing

The same filter (set of weights) is applied at every position in the image. An edge detector works the same whether the edge is top-left or bottom-right.

Hierarchical Features

Early layers detect simple features (edges, colors). Deeper layers detect complex features (shapes, parts, objects). Automatically learned!

Convolution Operation — Step by Step

A filter (kernel) of size k×k slides across the input image. At each position, it computes a dot product (element-wise multiply then sum) producing one value in the feature map.

Key CNN Formulas

Output Size = ⌊(Input − Filter + 2×Padding) / Stride⌋ + 1
Parameters in Conv Layer = (F × F × C_in + 1) × C_out

Example: Conv layer, input 32×32×3, filter 5×5, 64 filters, no padding, stride 1

Output = (32−5+0)/1 + 1 = 28 → Output shape: 28×28×64

Parameters = (5×5×3 + 1) × 64 = 76 × 64 = 4,864 parameters

Pooling — Spatial Dimension Reduction

Max Pooling (most common)

Takes the maximum value in each pooling window. Preserves the strongest feature activation. Most invariant to small shifts.

2×2 Max Pool, stride 2: input 28×28 → output 14×14 (halves each dimension)

Average Pooling

Takes average of all values in the window. Smoother downsampling. Used in GoogLeNet, some modern architectures. Global Average Pooling = average over entire feature map.

VGGNet (2014) — Simonyan & Zisserman (Oxford)

Philosophy: "Use Only 3×3 Filters, Go Very Deep"

Key Finding: Depth matters more than large filter sizes. Two 3×3 conv layers have the same receptive field as one 5×5 layer, but with more parameters and non-linearities.

Result: VGG-16 (16 layers), VGG-19 (19 layers). 2nd place ImageNet 2014. Still widely used as feature extractor.

Why 3×3 is Special
  • Two 3×3 layers = one 5×5 receptive field
  • Three 3×3 layers = one 7×7 receptive field
  • But 3×3 has fewer parameters: 2×(3×3) = 18 vs 5×5 = 25
  • More non-linearities (one ReLU per layer) → more expressive
VGGNet Weakness
  • 138 million parameters — very large model
  • Slow to train and deploy
  • Mostly in fully connected layers (FC has 122M of 138M params)
  • High memory consumption

ResNet (2015) — Kaiming He et al. (Microsoft Research)

The Problem ResNet Solved

When adding more layers to VGG (going from 16 to 30 layers), training accuracy on training data actually got WORSE. Not overfitting (test error) — the training error itself increased! This is called the degradation problem.

Expected: Deeper = better (or at least same). Observed: 30-layer network performed worse than 20-layer on training data. Why?

ResNet's Solution — Residual Learning

Instead of learning the desired mapping H(x) directly, learn the residual F(x) = H(x) − x. The output becomes: H(x) = F(x) + x

The identity mapping x is added via a "skip connection" that bypasses 2-3 layers. If the added layers aren't helpful, the network can simply learn F(x) = 0 → then output = 0 + x = x (identity). This is much easier to learn than direct identity mapping!

Sequences

Recurrent Neural Networks (RNN)

CNNs are for spatial data. RNNs are for sequential data — where the order of inputs matters. Text, speech, time series, music.

Why Can't CNN/MLP Handle Sequences?

The Problem

Consider sentence: "The cat sat on the mat." A feedforward ANN processes each word independently. It has no memory of previous words. So predicting the next word is impossible — you need context!

Also, sentences have variable length. MLP needs fixed-size input. RNN can handle any length.

The Core RNN Mechanism

hₜ = tanh(Wₕ·hₜ₋₁ + Wₓ·xₜ + b)
yₜ = Wᵧ·hₜ + bᵧ    [if output needed at this step]

The key insight: hₜ₋₁ (previous hidden state) acts as memory — it carries information from all previous time steps!

Types of RNN Architectures

TypeInput → Output PatternUse CasesExample
One-to-One1 input → 1 outputRegular classification/regressionImage classification (no memory needed)
One-to-Many1 input → sequence outputGenerative tasksImage → generate caption words one by one
Many-to-OneSequence input → 1 outputClassification of sequencesMovie review → positive/negative sentiment
Many-to-Many (sync)Sequence → same-length sequenceLabeling every elementWord → POS tag at each position
Many-to-Many (async)Sequence → different-length sequenceSequence transformationEnglish sentence → French sentence (translation)

BPTT — Backpropagation Through Time

Training RNNs uses BPTT — the RNN is "unrolled" across time steps, and standard backpropagation is applied to this unrolled graph.

The Vanishing Gradient Problem in RNNs

For a sequence of length T, the gradient of the first time step involves T multiplications of small numbers (gradients < 1). After 50+ steps, the gradient ≈ 0 → the network completely forgets early context.

Example: "The cat, which was very hungry after waiting for hours, finally ___." The blank should be "ate" — but "cat" (the subject) is 8+ words back. Simple RNN fails to connect them.

Solution: LSTM and GRU (next section)

Memory

LSTM & GRU — Solving the Memory Problem

LSTM and GRU use gating mechanisms to selectively remember and forget information, solving the vanishing gradient problem in RNNs.

LSTM — Long Short-Term Memory (1997)

Proposed by Hochreiter & Schmidhuber (1997). Uses a cell state Cₜ (the "long-term memory highway") and 3 gates to control information flow.

The Cell State — The Key Idea

The cell state Cₜ is a separate "conveyor belt" that runs through the entire sequence with only minor, controlled modifications. Information can flow unchanged over many steps. This is what enables long-term memory.

LSTM's 3 Gates — Explained in Detail

1. Forget Gate (fₜ)

Formula: fₜ = σ(Wf·[hₜ₋₁, xₜ] + bf)

Output: [0, 1] for each cell state value

Meaning: 0 = completely forget this memory; 1 = completely keep this memory

Example: Reading a new subject in a paragraph → forget the old subject's gender

2. Input Gate (iₜ) + Candidate

Formula: iₜ = σ(Wi·[hₜ₋₁, xₜ] + bi)

Candidate: C̃ₜ = tanh(Wc·[hₜ₋₁, xₜ] + bc)

Meaning: Which new information to add to cell state?

Example: New subject appears → store its gender in cell state

3. Output Gate (oₜ)

Formula: oₜ = σ(Wo·[hₜ₋₁, xₜ] + bo)

Output: hₜ = oₜ ⊙ tanh(Cₜ)

Meaning: What part of cell state to output as hidden state?

Example: If next word is a verb, output relevant subject info

LSTM Cell State Update

Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ

⊙ = element-wise multiplication. Forget gate removes old info. Input gate adds new info. The cell state is updated smoothly, avoiding vanishing gradients!

GRU — Gated Recurrent Unit (2014)

Proposed by Cho et al. (2014). Simplifies LSTM — merges cell state + hidden state, and uses only 2 gates:

Reset Gate (rₜ)

rₜ = σ(Wr·[hₜ₋₁, xₜ])

Controls how much of the past hidden state to use when computing the new candidate. rₜ≈0 → ignore past; rₜ≈1 → use all past.

Update Gate (zₜ)

zₜ = σ(Wz·[hₜ₋₁, xₜ])

Controls how much of old hidden state to keep vs. new candidate. Combines LSTM's forget + input gate into one.

h̃ₜ = tanh(W·[rₜ⊙hₜ₋₁, xₜ])     hₜ = (1−zₜ)⊙hₜ₋₁ + zₜ⊙h̃ₜ

Context

Bidirectional RNN (Bi-RNN)

Regular RNNs only look at past context. Bidirectional RNNs read the sequence both forward and backward to understand the full context at every position.

The Motivation

Why We Need Future Context

Consider: "I went to the bank to deposit money." vs "I sat on the river bank and fished."

The word "bank" means something different in each sentence. To correctly understand "bank", you need to see words that come AFTER it ("deposit money" vs "fished"). A forward-only RNN can't do this!

In NLP tasks like Named Entity Recognition, POS tagging, machine translation — both past and future context are essential.

Architecture

At each position, the output is the concatenation (or sum) of the forward and backward hidden states: yₜ = [h⃗ₜ ; h⃖ₜ]

Applications

TaskWhy Bidirectional Helps
Named Entity Recognition (NER)"Apple Inc. is a company" vs "I ate an apple" — need full sentence context to classify "Apple"
POS Tagging"Can you help?" — "can" is auxiliary verb; seeing "help" after confirms it
Machine Translation (encoding)Encoder reads entire source sentence before generating translation
Speech RecognitionAcoustic context from both sides helps disambiguate phonemes
BERTPre-trained using masked language modeling — uses both directions
Bi-RNN Limitation

Cannot be used for real-time generation tasks (like chatbots, speech synthesis) because you need the entire sequence before processing any part. For generation, use standard left-to-right RNNs.

NLP Pipeline — Complete Guide

Raw text cannot be fed directly into machine learning models. The NLP pipeline transforms messy human text into numerical representations that models can learn from.

Full Pipeline Overview

Raw Text Input "The quick brown foxes are RUNNING across the Fields!! Visit http://example.com" ↓ STEP 1 — Text Cleaning • Remove URLs, HTML tags, special characters • Fix encoding issues (UTF-8) • Lowercase: "the quick brown foxes are running across the fields" ↓ STEP 2 — Tokenization • Split into tokens: ["the","quick","brown","foxes","are","running","across","the","fields"] ↓ STEP 3 — Stop Word Removal • Remove: "the", "are", "across" • Result: ["quick","brown","foxes","running","fields"] ↓ STEP 4 — Stemming / Lemmatization • Stem: "foxes"→"fox", "running"→"run", "fields"→"field" • Result: ["quick","brown","fox","run","field"] ↓ STEP 5 — POS Tagging / NER • Tag: quick(JJ), brown(JJ), fox(NN), run(VB), field(NN) ↓ STEP 6 — Vectorization / Embeddings • Convert each token to a dense numerical vector • "fox" → [0.23, -0.81, 0.45, ..., 0.12] (300 dimensions) ↓ Numerical Matrix → Input to ML/DL Model

Step 2 — Stop Words

Stop words are high-frequency words with little semantic meaning. Removing them reduces noise and dimensionality.

Common stop words: theisareaanatwhichoninofit

When NOT to Remove Stop Words

Sentiment analysis: "not good" → removing "not" → "good" = completely wrong!

Question answering, translation: stop words carry grammatical meaning.

Modern neural models (BERT, GPT) don't remove stop words — they process the full sequence.

Step 6 — Text Vectorization Methods

Bag of Words (BoW)

Create a vocabulary of all unique words. Represent each document as a vector of word counts.

BoW Example

Vocabulary: ["cat", "dog", "mat", "sat"]

"cat sat on mat" → [1, 0, 1, 1] (cat=1, dog=0, mat=1, sat=1)

Problems: Ignores word order. Sparse high-dimensional vectors. No semantic meaning.

TF-IDF (Term Frequency — Inverse Document Frequency)

TF(t,d) = count(t in d) / total words in d
IDF(t) = log(N / df(t))     [N = total docs, df(t) = docs containing term t]
TF-IDF(t,d) = TF(t,d) × IDF(t)
TF-IDF Intuition

Word "the" appears in all documents → IDF ≈ 0 → TF-IDF ≈ 0 (filtered out)

Word "photosynthesis" appears in few docs → high IDF → high TF-IDF when it appears (important!)

TF-IDF automatically identifies the most informative words in each document relative to the corpus.

Word Embeddings — Word2Vec & GloVe

Instead of sparse one-hot vectors (50,000 dimensions), map each word to a dense vector (100-300 dimensions) that captures semantic meaning.

MethodApproachKey Property
One-Hot Encoding"cat" = [0,0,...,1,...,0] (50K dims)No semantic info; orthogonal vectors
Word2Vec (CBOW)Predict target word from context wordsSimilar words → similar vectors; linear relationships
Word2Vec (Skip-gram)Predict context words from target wordBetter for rare words; slower to train
GloVeFactorize word co-occurrence matrixCaptures global corpus statistics
FastTextWord2Vec + subword embeddingsHandles out-of-vocabulary words
BERT EmbeddingsTransformer, context-dependent"bank" has different vectors in different sentences
The Famous Word2Vec Arithmetic

Word2Vec learns embeddings where semantic relationships become vector arithmetic:

vector("King") − vector("Man") + vector("Woman") ≈ vector("Queen")

vector("Paris") − vector("France") + vector("Germany") ≈ vector("Berlin")

The model has learned concepts like royalty, gender, and country-capital relationships — purely from co-occurrence patterns in text!
